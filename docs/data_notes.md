# 데이터 전처리 내역

`design.md` 2.1과 `CLAUDE.md` 「데이터 취급」이 요구하는 기록이다.
심사에서 "이 데이터는 어디서 났나"는 거의 확실히 나온다. 그 답변의 근거가 이 파일이다.
